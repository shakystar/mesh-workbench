# 인체 도식 도구·캐릭터 제작 목표

2026-10-24 사용자 승인으로 goal을 활성화했습니다. 의상·머리카락은 이번 목표에서 제외합니다.
현재 절차적 캐릭터를 기준으로 부위별 도구를 구현하고, 마지막에는 서로 다른 얼굴·체형 설정에서 재사용합니다.

## 완료 기준

| 단계 | 산출물 | 완료 기준 |
| --- | --- | --- |
| A 얼굴 | 눈꺼풀–안구, 입술–인중–턱, 기존 코 도구 통합 | 출처가 있는 관계 도식, 부위별 등록값, 보호 영역, 실제 정면·사선/측면 결과 |
| B 귀·목 | 귓바퀴 주요 능선과 목–턱–어깨 연결 | 국소 형상과 연결부 확인, 얼굴 보호 |
| C 몸통 | 흉곽·복부·등·골반 연결 제어 | 앞·옆·뒤 실루엣 및 주요 표면 관계 확인 |
| D 팔·손 | 상완·전완, 손바닥·손가락 관절 구획 | 손가락 분리·연결과 관절 위치 제어, 몸통 보호 |
| E 다리·발 | 대퇴·무릎·하퇴, 발목·발등·발가락 구획 | 주요 방향의 형태와 연결부, 골반 보호 |
| F 전신 통합 | 한 캐릭터의 저장 모델과 도식 | 각 부위 결과를 실제 저장 모델에서 함께 확인 |
| G 재사용 | 얼굴과 체형이 다른 두 번째 캐릭터 | 같은 API와 별도 등록값으로 생성, 전후/변형 비교, 실패 입력과 한계 기록 |

각 단계에서 해부학적 관계와 조형용 치수를 구분합니다. 자료 출처·랜드마크·보호 규칙·실행 레시피를 기록합니다.
기능 실행, 기하학 검사, 시각적 결과는 별개의 완료 항목입니다. 수치 통과만으로 사실적인 인체 완성을 선언하지 않습니다.
임의 메시 자동 인식, 보편적 인체 정확도, 완성된 리깅·애니메이션은 목표가 아닙니다.

## 실행 제한

한 번에 부위 하나를 진행합니다. 해당 변경의 기하학적 효과와 실패 경로만 검사합니다.
Blender는 한 번에 하나, CPU·수치 라이브러리 2스레드입니다. 통과한 검사를 근거 없이 반복하지 않습니다.
원본은 보존하고 변형은 복귀 가능한 레이어, 토폴로지 수정은 새 객체에 저장합니다.
폴더당 직접 파일은 10개 이하이며 `.git`·`.venv`는 제외합니다.
생성물은 `runs/`, 공개 이미지는 포함된 절차적 예제만 사용합니다.

## 진행

- A 정적 도구 적용·검토 기준 충족: [눈꺼풀](EYELID_SUPPORT.md), [입술·인중](ORAL_RELIEF.md), [턱 윤곽과 단계별 근거](CHIN_CONTOUR.md)를 현재 저장 모델에 통합했습니다. 원본 보호·복귀·실패 경로·저장본·전후 렌더를 확인했습니다. 사실적인 얼굴 완성이나 해부학적 정확성을 뜻하지 않습니다.
- B 진행 중: [귀의 국소 세분화·연속 경로·연결부 완화](AURICLE_RELIEF.md#continuous-path-pass)를 적용했습니다. 원본·보호·복귀·실패 복구·저장본 검사와 렌더에서 능선의 연속성을 확인했습니다. 귀 두께가 얕고 접합부가 단순한 한계는 남습니다.
- B 국소 도구 적용·검토 기준 충족: 목 경로의 얼굴·귀 보호와 귀 능선 검토에 더해, [턱 밑 접힌 면 재구성](NECK_TRANSITIONS.md#bounded-patch-reconstruction)으로 12개 단면의 단일 교차와 저장본 렌더에서 돌출 제거를 확인했습니다. 원본·경계·외부 형상 보존, 실패 복구와 봉합 검사도 통과했습니다. 얕은 귀 두께와 단순한 근육 표현은 한계로 남습니다.
- 다음 실행 C: 흉곽–복부–골반의 관계 도식과 현재 전후·측면 형상을 대조하고 몸통 제어를 구축합니다.
- 코 관련 기존 도구는 보존하며 완성된 해부학 모델로 취급하지 않습니다.
- C 정적 도구 적용·검토 기준 충족: 몸통·복부·등·겨드랑이 연결에 이어 [허리 옆면·골반 위쪽 제어](body/TORSO.md#stage-c-handoff)를 적용했습니다. 원본·보호·복원·실패 복구·저장본 검사와 실제 전후 렌더 근거를 기록했습니다. 얕은 견갑부·늑골 경계 굴곡·큰 겨드랑이 홈은 남으며 해부학적 완성을 뜻하지 않습니다. 다음 D는 상완·팔꿈치·전완, 이후 손·손가락입니다. 전체 goal은 활성 상태입니다.
- D 진행 중: 양팔 볼륨에 이어 [팔꿈치 각각 20개 제어점](body/ARMS.md#elbow-profile)을 적용했습니다. 원본·보호·복원·두 번째 팔 실패 복구·저장본 검사와 뒤·바깥쪽 전후 렌더를 확인했습니다. 팔꿈치는 아직 둥글며 손가락은 미완료입니다. 다음은 손목·손바닥 연결, 이후 손가락 분리입니다.
- D 손 구조: 원본이 손가락 없는 덩어리임을 확인해 형상 생성부터 진행했습니다. [별도 다섯 손가락 도구](body/HANDS.md)의 연결·밀폐·지정 단면 틈·원본 보존·실패 복구·저장본 검사를 통과했습니다. 손바닥과 손가락 사이 연결은 투박하며 캐릭터 손목에는 아직 결합하지 않았습니다. 다음은 손바닥·연결부 조형과 손목 경계 결합입니다.
- D 손 결합: [양손 손목 봉합](body/HANDS.md#bilateral-wrist-graft)을 새 몸체 스냅샷에 적용했습니다. 기존 경계·잔존 정점 보존, 봉합·실패 복구·저장본 검사를 통과했습니다. 원본 레이어와 선택은 원본에 남깁니다. 손목 띠와 평평한 손바닥이 남아 다음은 해당 연결부 조형입니다.
- D 손목 진단: [매우 짧은 연결면 변과 브러시 거부](body/HANDS.md#wrist-fairing-rejection-and-stock-vertex-weld)를 기록하고 새 손 쪽 정점만 각각 50개 병합했습니다. 원본·잔존 정점 보존과 저장본 검사는 통과했으나 손목 띠는 미해결입니다. 다음은 중간 손목 단면을 추가하는 연결면 재구성입니다.
- D 손목 재구성: [중간 단면 4개와 국소 완화](body/HANDS.md#intermediate-wrist-sections-and-successful-fairing)를 적용했습니다. 기존 보호·복원·실패 복구·저장본 검사와 렌더를 확인했으며 이동 한도와 면 뒤집힘 기준은 유지했습니다. 완만한 손목 굴곡은 남습니다. 다음은 손바닥·손가락 사이 연결부 조형입니다.
- D 손바닥: [양손 각각 40개 제어점](body/HANDS.md#registered-palm-cupping-and-web-arch)으로 손바닥 볼륨과 손가락 시작선 곡선을 적용했습니다. 보호·복원·실패 복구·저장본 검사와 여섯 손가락 틈 검사를 통과했습니다. 엄지 뿌리 단차와 각진 손바닥은 남아 다음 대상으로 잡았습니다.
